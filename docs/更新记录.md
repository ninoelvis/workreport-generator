# 更新记录

## v2.1.0（2026-11-22）· 当前版本

这一版做了四件事：**修好统计页被底栏挡住**、**把统计图表改清楚**、
**开发者页面补上最近新功能的调试入口**、**全 App 的动效统一**。
导出、加密、命名、密码、分享、邮件这些**一条红线都没动**。

### 🐛 修好：统计页底部被导航栏挡住
统计页滚到底时，最后那段「统计只包含本 App 生成的 N 份报告…」的说明文字，
会被悬浮在右下的玻璃胶囊底栏**压在底下看不见**。

根因：底栏是**浮在内容之上**的，不占布局位置，所以内容要自己让开。
首页、「我的」、历史列表三处都写了让位空间，**唯独统计页漏了**。现在补上了。

### 📊 统计图表改清楚了：一张图只说一件事
之前的「工作条目分布」把两件事塞进同一根柱子：
柱高是工作条目数、柱底再叠一段深色是报告份数。问题有三个：

1. **深色模式下那段"深色"其实是白色**（用的是 `onPrimary`），
   和卡片上"深色柱 = 报告份数"的提示正好相反；
2. 某个月的报告份数刚好是最多的时候，整根柱子会被盖成同一个颜色，看着像空白；
3. 只有两三根柱子时又被均分到左右两端，中间大片空白，更看不懂。

现在改成**单一指标**：柱子只表示工作条目数，
**柱顶直接写条数、柱子下面写那段时间生成了几份周报**，一眼就能读。
柱子数量少的时候会**居中紧凑排列**，不会再被拉到两边。

### 🧰 开发者页面：最近新增的功能都能调了
隐藏的调试页（我的 → 关于 → 连点版本号 7 次）新增了几组入口，
对应最近几个版本加的功能，不用再手工造数据就能验证：

- **统计样本数据工厂**：一键造 12 / 24 份**真的**加密 ZIP 报告
  （预览、再次下载、再次发邮件都能试），只是时间挪到了过去几个月，
  这样统计图表立刻有内容。样本只落在应用私有目录，**不会写进你的「下载」目录**，
  也能一键清掉。
- **搜索命中自检**：输入关键词，直接告诉你命中了几条、
  其中几条是命中文件名、几条是**只命中正文**（"记得上周写了什么也能搜到"的关键）。
- **主题即时切换**：浅色 / 深色 / 跟随系统，一点就切。
- **动效开关与速度**：整个 App 的动效可以**全局关掉**，也能调快调慢。
- **图标资源自检**：列出各密度的桌面图标与 App 内字标资源是否齐全、实际尺寸多少。
- **周范围自检**：打印本周 / 上周算出来的时间区间和解压密码基准日。

### ✨ 全 App 的动效统一了
之前各个地方的动画时长是手写数字，散在十几个文件里，
改的时候很容易漏一处，久了就变成"半个 App 有动效、半个没有"。

现在统一收口到一处（4 档时长），并且：

- **点开一条历史报告时，内容缓缓展开 + 淡入**（之前是瞬间出现，像"啪"地一下蹦出来）；
- **列表 / 统计 两个视图切换**改成淡入；
- **搜索框出现和消失**带展开动画；
- **统计页「按月 / 按周」切换**时图表淡入淡出；
- 卡片按压回弹、多选勾选框弹出、批量条滑入、底栏指示条平移 —— 全部走同一套规格。

### 🔒 红线一个字没动
导出内容、Excel 样式、加密 ZIP 文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**，与 v2.0.3 **逐字节相同**。

单元测试 **301/301** 通过（新增 11 项：统计页底部避让、图表单一指标契约、
开发者调试入口齐全、样本不污染下载目录、展开动效契约、全 App 动效时长统一收口）。

## v2.0.3（2026-11-22）

这一版是**图标修订版**：桌面图标按新设计稿改成**纯文字**，
App 里的图标位也换成同一套字标。
**导出、加密、命名、密码、分享、邮件这些一条红线都没动。**

### 🎨 桌面图标：纯文字「WorkReport」
按设计稿，桌面图标**只有一行字，没有任何图形**：
白底 + 横排「WorkReport」——「Work」灰蓝、「Report」深藏蓝。

字形是**直接从设计稿原图抠出来的**，不是找相近字体重排，
所以笔触、字重跟设计稿一模一样。

技术上做了四处调整：

1. **自适应图标前景换成横排字标** ——
   Android 的圆形遮罩**只保留 108dp 画布的中心 72dp**，
   字标宽度按实际遮罩标定成 68dp，
   圆形、圆角方形、全出血方形三种桌面形态下都不会被裁掉。
2. **新增单色主题图标**（`ic_launcher_monochrome`）——
   Android 13+ 的「主题图标」会把图标按系统主题重新染色，
   之前是拿彩色前景充数的，染出来是一坨。现在单独给了一份单色字标版。
3. **启动图单独一份**（`ic_launcher_splash`）——
   系统启动时会把图标放大到画布 2/3，字太小会糊成一团。
4. **背景改成纯白** —— 跟设计稿一致，不再是渐变底。

### 🔒 桌面图标不再跟随系统深浅色
之前桌面上有两套图标（`mipmap-night-*`），系统切深色时图标会跟着变。
现在**只剩一份**，浅色桌面和深色桌面上是同一个图标，不会跳来跳去。

已删除：5 个 `mipmap-night-*` 目录 + `drawable-night/ic_launcher_background.xml`。

**App 内的深浅色切换不受影响** —— 那套是 App 自己手动管的（Compose 主题），
跟桌面图标是两回事，首页/历史/我的三个页面的深浅色切换照常。

### ✨ App 里的图标位换成同一套字标
首页和引导页顶栏，原来是个 **42dp 圆角方框 + 1dp 边框 + 底色**，里面放品牌图形标志。
现在：

- **去掉边框、去掉底色方块** —— 字样直接和页面背景**融为一体**
- **换成同一套 WorkReport 字标**，跟桌面图标长得一样
- 字标拆成「Work」「Report」两段**单色**图，运行时按主题染色，
  **深浅色自动跟随**，不用维护两套图

### 🔒 红线一个字没动
导出内容、Excel 样式、加密 ZIP 文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**，与 v2.0.2 **逐字节相同**。

单元测试 **290/290** 通过（新增图标契约测试：桌面图标是纯文字、App 内顶栏无边框无底色、App 内字标资源齐全且随主题染色）。

## v2.0.2（2026-11-22）

这一版是**修 bug + 加统计维度**：先修好 v2.0.1 引入的显示错乱，再把搜索整合到一起，统计加上新的维度。

### 🩹 修复：历史报告页卡片正文压住操作按钮（显示严重错乱）
**这是 v2.0.1 引入的回归**，先说清楚它是怎么来的：

v2.0.0 给「多选」加了动效，卡片内容区套了一个 `AnimatedVisibility`（进入多选时内容缓缓收起）。
但 Compose 的 `AnimatedVisibility` 有一条硬约束 —— **它的 content 只能放一个子节点**，
它会把 content 当成一个整体来测量和绘制。

而当时 content 里直接堆了「时间/密码/大小 → 正文摘要 → 操作按钮 → 预览表格」好几层，
于是它们被**叠放在同一个位置**：正文摘要压在操作按钮上，两坨字糊成一团（截图里就是这样）。

现在 content 整体包了一层 `Column`，每一层各归各位，显示恢复正常。
同时补了一条**防回归测试**，逐个点名检查每一处 `AnimatedVisibility` 的形状，以后再写错会被测试拦下。

### 🔍 搜索整合到一个输入框
之前搜索框下面有两个开关：「文件名 / 全部内容」，要用户先想清楚搜哪一类，很别扭。

现在**一个搜索框同时搜文件名和周报正文**：
- 记得文件名 → 直接命中；
- 只记得「上周写了什么」→ 也能在正文里搜到；
- 搜的仍然是**你自己写的原文**（不是脱敏后的文本），所以写「张三」就能搜到「张三」。

顺带把「文件名 / 全部内容」两个枚举和切换控件都删了，代码更干净。

### 📊 统计新增三个维度
原来只有「按月」这一个维度，现在：

1. **按月 / 按周 切换** —— 统计区顶部加了下划线 Tab（和页面顶部「列表 / 统计」同一套视觉语言）。
   按周能看出「一个月里第几周产出最高」。
2. **每份报告的产出** —— 新增区块，列出**写得最细的三份报告**（各写了几条），
   总览里也补了「平均每份」。
3. **总览补全** —— 多了「平均每份」「最忙的月份」「最忙的一周」三块。

柱状图还是 Compose `Canvas` 手绘，**零第三方依赖**没变。

### 🔒 红线一个字没动
导出内容、Excel 样式、加密 ZIP 文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**，与 v2.0.1 **逐字节相同**。

单元测试 **285/285** 通过（新增 9 项：卡片重叠防回归、搜索整合契约、统计新维度计算）。

## v2.0.1（2026-11-22）

这一版修三件事：**多选要有动效**、**返回手势后底栏不能再消失**、**顶部的「列表 / 统计」要跟整体风格统一**。

### ✨ 多选现在有动效了
之前进入多选是**瞬间切换** —— 卡片内容「啪」地塌缩成一个标题，像卡了一下。

现在整套动效和 v1.8.0 的玻璃底栏**用同一套语言**：
- 卡片内容**缓缓收起 / 展开**（淡出 + 高度收缩，不是瞬间塌缩）；
- 右上角的**勾选框弹出来**（缩放 + 淡入，弹簧手感）；
- 勾上时**对勾弹一下**，圈圈颜色平滑过渡；
- 底部**批量操作条从下方滑入**，和玻璃胶囊的淡出下沉**反向呼应** —— 一个退场一个进场，视觉上是「交接」而不是「打架」；
- 卡片和按钮都有**按下回弹**（按下缩到 0.97 / 0.82，松手弹回）。

### 🩹 修复：多选后按返回手势，底部导航栏永久消失
**根因**：多选状态是全局标记，之前**只有「取消」按钮和批量操作完成**会清它。
系统返回手势、切换 Tab 都不走那条路 → 标记卡在「多选中」→ 底栏就一直不显示
（切到别的 Tab 也一样，因为底栏是全局的）。

现在改成**双保险**：
1. 多选时按返回手势 → **只退出多选**，不离开这个页面，玻璃胶囊浮起（符合 Android 惯例）；
2. **只要离开历史报告页**（切 Tab、返回、退出 App），多选状态一律自动清掉。

另外把多选状态的**真相源统一成一份** —— 之前底栏和卡片各存一份，清了一处另一处还留着，
这正是「底栏消失」的深层原因。

### 🎨 顶部「列表 / 统计」换成下划线样式
之前那个「灰底槽 + 白块」的分段控件，是整个 App 里**唯一的异类** —— 别处都是卡片和玻璃胶囊，
它就显得孤零零。

现在改成**下划线 Tab**：文字 + 下方一条短横线，切换时**指示条平滑平移**。
这和 v1.8.0 底部玻璃胶囊的指示条是**同一套视觉语言**，顶部和底部串起来了，
而且天然带动画（指示条平移 + 文字颜色过渡）。

### 🔒 红线一个字没动
导出内容、Excel 样式、加密 ZIP 文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**，与 v2.0.0 **逐字节相同**。

单元测试 **266/266** 通过（新增 7 项：返回手势拦截、离开页面兜底、单一真相源、
Tab 样式契约）。

## v2.0.0（2026-11-22）

这一版做了一件事：**让这个工具在用了半年、攒了几十份报告之后，依然好用**。

### 🔍 搜索现在能搜到正文了
以前搜索**只匹配文件名** —— 可你想找的往往是「上周写了什么」，
而不是「张三-2026年10月第3周工作报告」这种文件名。

现在搜索框下面多了一个切换：
- **文件名** —— 原来的行为，不变；
- **全部内容** —— 连标题、时间范围、本周完成、下周计划一起搜。

两个细节：
- 搜的是你**自己写的原文**，不是脱敏后的文本（否则你写「张三」却搜不到，因为里面已经换成拼音了）；
- 输入里的 `%` 和 `_` 现在会被**正确转义**，搜 `50%` 不会变成匹配所有含 `50` 的行。

### 📊 新增「周报统计」
历史报告页顶部多了一个 tab：**列表 / 统计**。

统计里有总览（报告份数、工作条目、覆盖月份）、**每月工作条目柱状图**（柱子里深色的一段是报告份数）
和每月明细表。

诚实说明：统计**只包含本 App 生成的报告**。
你自己拷进存放目录的压缩包不在其中，页面上也写明了这一点 —— 不会让你误以为漏了文件。

### 🗑️ 历史报告支持批量操作
**长按任意一份报告**进入多选：
- 多选时卡片会**精简**，只留标题和勾选框，一眼看清有哪些、选中了哪些；
- 底部浮出操作条：**全选 / 再次下载 / 删除**；
- 删除会**连本机的压缩包一起删掉**（不只是删列表里的记录）。

「载入首页」「取回下周计划」是单选语义（会互相覆盖），「批量发邮件」的多附件也可能超限，
所以这两项**没有做成批量**。

### 📅 时间范围可以一键选
「本周工作时间」下面多了「本周」「上周」两个快捷按钮，不用再手打日期。

⚠️ 这两个按钮走的是和默认值**完全相同的格式化逻辑**，
所以写进 Excel 的那一格格式不会变。

### 🔒 隐私加固（这一版最实质的变化）
之前 App 嘴上说「所有内容只存在本地」，但**系统云备份会把东西打包带走** ——
历史报告正文、敏感词库明文、姓名、草稿，都在备份范围里。
现在做了两件事：

**1. 彻底关掉系统云备份**
`allowBackup="false"` + 备份规则双重排除（云备份和设备迁移都排除）。
这跟「所有内容只存在本地」的承诺完全一致了。

> **换手机怎么办？**
> · 设置、模板、敏感词库 → 用「我的 → 配置备份 / 恢复」导出一个加密 ZIP，再导入；
> · 已生成的周报 → 压缩包就在你选的存放目录里，直接拷过去；
> · 历史报告的**列表记录**不随系统迁移 —— 这是关掉云备份的代价，

## v1.7.0（2026-11-21）

### 🧊 底部导航换成液态玻璃
底部导航不再是压在页面底部的一条实心色块，改成 **iOS 风格的悬浮玻璃胶囊**：
浮在内容之上，**真正模糊背后的内容** —— 滚动时能看到后面的卡片、文字被磨砂，

技术路线是**手写官方 API，零第三方依赖**：

> 关键点：`RenderEffect` 只能模糊「自己这一层画的东西」，
> 单纯给底栏挂个 renderEffect 是没用的（模糊的是纯色，等于没模糊），
> 必须先把背景内容录进图层再采样 —— 这也是为什么背景层和玻璃层要分开。

## v1.0.0（2026-10-22）

首个整理发布的版本。功能演进过程见下。

### ✨ 首次启动引导
首次打开自动展示**功能介绍**与**版本更新记录**两张卡片，
勾选「不再自动显示」后不再打扰；顶部 ℹ️ 按钮随时可重新打开。
另提供「重置全部本地数据（含姓名）」入口。

### 🧹 分区清除
- 「本周已完成工作梳理」「下周工作计划」各自标题右侧有独立的 `🧹 清空` 按钮，互不影响
- 底部「🗑️ 清除全部数据」一键重置（连同工作记录一起清，姓名保留）

### 🌗 界面改版
按飞书 / 钉钉办公效率软件风格重做：
顶部品牌栏、面板标题图标、表单标签图标、三张信息统计卡片、
统一图标按钮、记录删除改 🗑 图标、浅色 / 深色双主题。

### 📨 发送邮箱可自选并记忆
- 首次生成时弹窗让你挑一个用来发邮件的 App，**选完自动记住**
- 之后每次直接用该 App 拉起，不再打扰
- 主界面「发送邮件使用的应用」处可随时「选择 / 更换」
- 列表**只显示邮箱类应用**（微信 / QQ / 微博等分享类应用不再出现）
- 默认 App 被卸载后自动清空并重新让你选

### 📋 自动复制文件名 + 自动发邮件
生成加密 ZIP 的同时：
- 压缩包**文件名自动复制到手机剪贴板**
- **自动拉起阿里邮箱**（`com.alibaba.cloudmail`），把 ZIP 作为附件带入写邮件界面
  （依次兼容旧版 `com.alibaba.android.mail`、钉钉内置邮箱，并支持任意自选邮箱 App）

### 📦 基础能力
- 周报内容生成 → Excel 导出 → AES 加密 ZIP → 保存到系统「下载」目录
- 自动计算周数、文件名与 ZIP 解压密码（默认取本周周四，格式 `yyyyMMdd`）
- 实时预览最终 Excel 效果
- 工作记录逐条管理，一键汇总
- 浅色 / 深色主题切换
- 姓名与周报内容本机自动保存
- **完全离线可用**：不申请 `INTERNET` 权限，零外部资源依赖
