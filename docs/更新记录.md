# 更新记录

## v1.3.9（2026-10-23）· 当前版本

### 👁 历史报告直接预览 Excel
不用再手动解压压缩包了。

- 历史报告卡片新增「**查看内容**」，点开直接看到压缩包里那份 Excel 的样子
- 表格结构、合并单元格、列宽、换行都跟导出的文件**完全一致**，所见即所得
- 卡片上还会直接显示「本周完成」的**内容摘要**，瞄一眼就知道这周写了什么
- 生成报告时内容会一并存进本地数据库，所以**压缩包被清理掉了也不影响预览**

### 🗄 数据库升级
本地历史记录库从 v1 升到 v2，补齐了报告内容字段。
旧版本创建的报告没有完整内容，会降级成「只显示摘要」并给出提示，不会报错。

## v1.3.8（2026-10-23）

### ⚡ 快捷记录模板
常写的重复内容不用每次手敲了。

- 在首页「工作记录」区点「⚡ 快捷记录」，展开后点一下模板，内容直接进记录列表
- 「下周工作计划」同样有快捷模板，点一下就在框里追加一行，不会覆盖已写的内容
- **两套模板分开配置**，互不影响
- 模板在「我的 → 快捷记录模板」里维护，可以增删改

### 📂 「我的」页改成设置首页
以前所有配置都堆在一页上，现在每项点进去是一个独立的小页面：

- 👤 个人信息 · ⚡ 快捷记录模板 · 🛡️ 敏感词库 · 🌗 外观 · 📨 邮件设置
- 📄 功能介绍与更新记录 · 🧹 数据管理 · ℹ️ 关于

### 🎨 引导页全屏重做
- 引导页原来是弹窗，顶部会露出一条系统灰色底，现在改成**整页全屏**，和首页完全一致
- 每个分区都可以**点标题展开 / 收起**，默认只展开「功能介绍」
- 顶部加渐变与版本徽章，更新记录的版本号改成小标签样式

## v1.3.7（2026-10-23）

### 📨 邮件发送回到标准通道
撤销阿里邮箱专用通道，所有邮箱 App 统一走标准的 `ACTION_SEND`：
主题和压缩包附件都会带上，收件人自己在邮箱里填。
顺带解决了部分机型上「点发送闪退」「邮箱拉不起来」的问题。

## v1.2.1（2026-10-22）· WebView 版最终版

### 🎨 App 内顶栏图标
此前只换了桌面图标，App 内部顶栏还是老的 📄 表情符号，现在一并换成新的卷轴+笔图标，
深色主题下也会自动换成深色底。

### 💡 桌面图标没变？
部分手机桌面会缓存应用图标，覆盖安装后不刷新新图（App 内部不受影响）。
引导页里已写明处理办法：重启桌面 → 清桌面缓存 → 实在不行才卸载重装（会清空本地草稿）。

## v1.2.0（2026-10-22）

### 🎨 全新的应用图标
换成「卷轴 + 笔」主题图标（紫蓝渐变描边，浅色渐变底），
已适配 Android 8+ 的**自适应图标**（圆形 / 方形遮罩都不会裁到主体）。

### 📱 状态栏 / 导航栏适配
之前系统状态栏和导航栏是系统默认的灰色，和浅色页面割裂开。
现在两者的颜色会**跟随页面主题**：浅色主题下与页面同色，深色主题下一起变深，
系统图标也会自动切换深浅，保证任何手机上都是一整块。

## v1.1.0（2026-10-22）

### 🛡️ 敏感词管理
顶栏 🛡️ 按钮打开顶部管理面板，可自行**增删改**敏感词库：
- 新增词自动按「小写拼音首字母」生成缩写（督办 → db），也可手工改

- 另有「恢复默认」一键回到内置 13 个词

## v1.0.0（2026-10-22）

首个整理发布的版本。功能演进过程见下。

### ✨ 首次启动引导
首次打开自动展示**功能介绍**与**版本更新记录**两张卡片，
勾选「不再自动显示」后不再打扰；顶部 ℹ️ 按钮随时可重新打开。
另提供「重置全部本地数据（含姓名）」入口。

### 🧹 分区清除
- 「本周已完成工作梳理」「下周工作计划」各自标题右侧有独立的 `🧹 清空` 按钮，互不影响
- 底部「🗑️ 清除全部数据」一键重置（连同工作记录一起清，姓名保留）

### 🌗 界面改版
按飞书 / 钉钉办公效率软件风格重做：
顶部品牌栏、面板标题图标、表单标签图标、三张信息统计卡片、
统一图标按钮、记录删除改 🗑 图标、浅色 / 深色双主题。

### 📨 发送邮箱可自选并记忆
- 首次生成时弹窗让你挑一个用来发邮件的 App，**选完自动记住**
- 之后每次直接用该 App 拉起，不再打扰
- 主界面「发送邮件使用的应用」处可随时「选择 / 更换」
- 列表**只显示邮箱类应用**（微信 / QQ / 微博等分享类应用不再出现）
- 默认 App 被卸载后自动清空并重新让你选

### 📋 自动复制文件名 + 自动发邮件
生成加密 ZIP 的同时：
- 压缩包**文件名自动复制到手机剪贴板**
- **自动拉起阿里邮箱**（`com.alibaba.cloudmail`），把 ZIP 作为附件带入写邮件界面
  （依次兼容旧版 `com.alibaba.android.mail`、钉钉内置邮箱，并支持任意自选邮箱 App）

### 📦 基础能力
- 周报内容生成 → Excel 导出 → AES 加密 ZIP → 保存到系统「下载」目录
- 自动计算周数、文件名与 ZIP 解压密码（默认取本周周四，格式 `yyyyMMdd`）
- 实时预览最终 Excel 效果
- 工作记录逐条管理，一键汇总
- 浅色 / 深色主题切换
- 姓名与周报内容本机自动保存
- **完全离线可用**：不申请 `INTERNET` 权限，零外部资源依赖
