# 更新记录

## v1.8.0（2026-11-22）· 当前版本

### 🩹 修复：深色模式底部一条白杠
深色模式下屏幕最下面（系统手势条那一区域）会浮出一条**浅色白杠**。

根因不在配色，而在两处「没人绘制」的地方：
一是主题文件里把**窗口底色写死成了浅色**，而深色模式是 **App 内手动切换**的
（不跟随系统深浅色），所以窗口底色永远是浅的；
二是内容区为了避开系统导航条把内容整体顶了起来，
导航条那条区域**没有任何 Compose 内容绘制**，浅色的窗口底就露了出来。

这次做了四道保险：
窗口底色改为**跟随 App 当前主题**（深色就是深色）、根容器整屏铺满主题底色、
系统状态栏/导航条一律**全透明**（不再按系统深浅色自动盖一层浅色遮罩）、
并关掉系统导航条的对比度强制遮罩。

顺带把**启动时的闪白**也修了：深色模式下启动图与窗口底色现在同样是深色，
不再先闪一下白再进主界面。

### 🔻 底部导航缩成一半宽，靠右显示
底栏从**横贯整屏**改成**窄胶囊**，宽度约为原来的一半（3 个图标 × 60dp = 180dp），
**整体靠右对齐**，不再霸占整个屏幕底部。

图标下方**去掉了文字**，只留图标本身；被选中时图标下面浮起一个小圆点高亮 +
一条短指示条，当前在哪一眼就清楚。

### 👆 点击切换加了回弹动效
按下图标时会有**轻微缩小**的按压反馈，松手**弹回**并带动选中圆点与指示条平滑平移；
图标大小、颜色也跟着过渡，不再是「啪」地一下切换。

### 🔮 玻璃更透，能看见底下的内容
玻璃的**模糊半径从 16dp 加大到 26dp**，同时把**玻璃自身的遮盖大幅调低**
（深色下 10% → 5.5%，浅色下 55% → 38%）。
效果是玻璃更「毛」但**更透** —— 滚动列表时，
能透过胶囊隐约看到下面卡片和文字在动，而不是一块灰扑扑的板子。

### 🔒 红线一个字没动
导出内容、Excel 样式、加密 ZIP 文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**。`ReportExporter` / `ReportNaming` / `SensitiveWordEngine` /
`ExternalZipPassword` / `ReportRepository` 与 v1.7.0 **逐字节相同**。

`GlassBottomBarTest` 增补 5 项防回归检查：
深色模式底部不许露白、窗口底色必须跟随主题、系统栏样式必须显式透明、
启动图必须有深色变体、玻璃遮盖不透明度必须够低。
单元测试 225/225 通过。

## v1.7.0（2026-11-21）

### 🧊 底部导航换成液态玻璃
底部导航不再是压在页面底部的一条实心色块，改成 **iOS 风格的悬浮玻璃胶囊**：
浮在内容之上，**真正模糊背后的内容** —— 滚动时能看到后面的卡片、文字被磨砂，
玻璃本身带细边框和顶部高光。

技术路线是**手写官方 API，零第三方依赖**：
用 Compose 的 `GraphicsLayer` 把整屏内容录制成一层（`layer.record { drawContent() }`），
玻璃控件再从这层里按坐标差平移采样，最后用 Android 12 起的 `RenderEffect`
做高斯模糊。玻璃拆成「模糊层 + 清晰层」，所以**边框和文字不会被一起糊掉**。

> 关键点：`RenderEffect` 只能模糊「自己这一层画的东西」，
> 单纯给底栏挂个 renderEffect 是没用的（模糊的是纯色，等于没模糊），
> 必须先把背景内容录进图层再采样 —— 这也是为什么背景层和玻璃层要分开。

### 🩹 修复：进入二级页面内容瞬间下移 64dp
以前底栏是**占布局位置**的，一从一级页面进二级页面、底栏消失，
`Scaffold` 给的内容区高度立刻变矮 64dp，页面就猛地往下跳一下。

现在底栏**浮在内容之上、不占任何布局位置**，内容区高度从头到尾不变，
进出二级页面**内容一点都不动**。
（同一个坑还堵了两道防线：不再用 `Scaffold.bottomBar` 插槽、
不再用 `innerPadding.calculateBottomPadding()` 算底部避让 —— 那个值会突变。）

进入二级页面时玻璃胶囊**淡出并下沉**，返回时**浮起**。

### 🎨 深浅色分别调参
浅色下是通透的白色毛玻璃，深色下整体压得更低（透明度 10%），
保证胶囊上的文字在任何主题下都看得清 —— 走 iOS 27 的可读性路线：
不靠重投影，靠**明确的细边框**把玻璃边界划出来。

### ⬆️ 最低版本提到 Android 12
玻璃背景模糊依赖 Android 12（API 31）起的系统渲染接口。
既然已经定了**不做降级**，就把最低支持版本从 Android 8 直接提到 **Android 12**，
不给不支持的设备留「半吊子玻璃」。

顺带修了一个连带问题：AGP 在 minSdk ≥ 28 时默认把代码**不压缩**打包，
APK 会从 12 MB 涨到 44 MB。已强制恢复压缩，**下载体积仍是 12 MB 上下**。

### 🔒 红线一个字没动
导出内容、Excel 样式、压缩包文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**。`ReportExporter` / `ReportNaming` / `EncryptedZipWriter` /
`SensitiveWordEngine` / `MailHelper` 与 v1.6.0 **逐字节相同**。

新增 `GlassBottomBarTest`（12 项）：锁住玻璃必须是真背景模糊、
必须拆模糊层与清晰层、不许引入第三方库、minSdk 必须是 31、
AppRoot 不许再出现 `Scaffold` / `calculateBottomPadding`、
底栏必须保留指示条平移与图标缩放与文字淡入、
一级页面必须留胶囊空间而二级页面不许留、
以及玻璃采样偏移的**符号方向**（反了会显示屏幕另一端的内容）。
单元测试 219/219 通过。

## v1.6.0（2026-11-21）

### 🎨 全套图标重做
App 里所有带图标的位置 —— 功能区、底部三个标签页、操作按钮、顶栏 Logo、空状态、
列表标签、输入框标题 —— 原来的 emoji 和系统自带图标**全部换成同一套自绘矢量图标**。

品牌标志 + **WorkReport** 字样。Android 会把启动图标裁成圆形/圆角方形，

自适应图标（`mipmap-anydpi-v26`）+ 各密度传统图标 + 深色版，全部齐备。

### 🎞 底部导航加了动画
底部导航改成**自绘**，不再用 Material 的 `NavigationBarItem`：

- 指示条在三个标签之间**平滑平移**（spring 动画）；
- 选中的图标放大到 **1.12**，没选中的缩到 **0.92**；
- 文字只在选中时**淡入**，未选中淡出（固定高度，不会顶动布局）；
- 页面之间加了轻微的**横向滑动 + 淡入淡出**过渡。

### 🔒 红线一个字没动
导出内容、Excel 样式、压缩包文件名、内层 Excel 文件名、解压密码规则、加密格式：
**完全没改**。`XlsxWriter` / `EncryptedZipWriter` / `ReportNaming` / `DateUtils` 与 v1.5.1 **逐字节相同**。

新增 `IconSystemTest`（9 项）：扫源码禁止再出现 emoji、禁止再使用 Material Icons、
禁止在矢量里写死 `android:tint`、要求全部 `R.drawable.ic_*` 引用都有对应资源、

## v1.5.1（2026-11-20）

### 🐛 修「当前存放位置」显示成了文件名
「我的 → 周报存放目录」里选好目录后，下面显示的应该是**你选的那个文件夹**，
结果显示的是**目录里第一个文件的文件名**。

原因：查目录名时去查了「这个目录下的子文档列表」，然后取了第一条 —— 那当然是文件名。
现在改成查**目录自身**，显示它真正的名字，并在下面补上**完整路径**
（例如 `/storage/emulated/0/Download/周报`），一眼看清选的是哪个文件夹。

### 🐛 修预览区表头高度不齐
「客户（及用户）反馈」这一列的表头换行后，把整行表头撑歪了 —— 别的列是一行字浮在顶部，
它是两行字占满整行，看着就像「这一列的高度有问题」。

Excel 的表头行高是**固定**的（28pt），预览现在也用固定行高：六列一样高、文字一样垂直居中，
长标题换行也不会把整行撑歪。

### 🐛 修「放大查看」里面一片空白
没填任何内容时点「放大查看」，全屏里什么也看不见（连表头和边框都没有）。

原因：横向滚动和纵向滚动套在了**同一个容器**上。`horizontalScroll` 会给子内容
「宽度无上界」的约束，而预览表里的 `fillMaxWidth()` 在宽度无上界时宽度会退化成 0 ——
整个表格宽度为 0，自然什么都看不见。

现在：横竖滚动**分层**（外层竖向、内层横向），表格宽度**写死**，
**没填内容时也能看到完整的表格样式**（标题行、表头、六列边框都在）。

### 🆕 历史报告页也能放大了
历史报告里的预览（数据库里的报告 + 手动拷进目录的压缩包）也加了「放大查看」，和首页一致。

### 🔒 红线一个字没动
导出格式、压缩包文件名、内层 Excel 文件名与样式、解压密码规则、加密格式：**完全没改**。
`XlsxWriter` / `EncryptedZipWriter` / `ReportNaming` / `DateUtils` 与 v1.5.0 **逐字节相同**。
新增 `NoMixedScrollContainerTest`：扫源码禁止「横竖滚动挂在同一个 Modifier 链上」，防止再犯。
单元测试 189/189 通过。

## v1.5.0（2026-11-20）

### 📁 存放目录自己挑
第一次打开时，引导页会多一张「存放周报的文件夹」卡片，点一下就能选一个目录存周报。
不选也照常用 —— 那就还是原来的手机「下载」目录，行为和以前完全一样。
随时可以在「我的 → 周报存放目录」里改，或者一键恢复默认。

用的是系统官方的文件夹选择器，**不需要申请任何存储权限**，换手机、卸载重装都不影响。

### 📥 手动拷进去的压缩包也认得
把压缩包手动拷进你选的目录，历史报告页会一并列出来（带「外部文件」标记），
可以直接**预览内容**，也能分享出去。

> 这里踩了个很深的坑：文件名里的「第 N 周」**不能唯一确定起始日**。
> 一个「第 3 周」对应的是一个 7 天的区间，起始日可能是其中任何一天，
> 也就是说密码有 7 个可能。所以不是去猜一个密码，而是**推出 7 个候选密码依次尝试**，
> 能解开那个就是它 —— App 自己生成的包必中。文件名被改过才需要手输一次。

### 🔍 预览可以放大了
预览卡片右上角多了「**放大查看**」，点开是全屏：
- 双指捏合缩放（1x ~ 4x）、双击在 1x / 2x 之间切
- 左右滑动看全部 6 列，上下滚动看完整内容
- 之前固定 132dp 高的单元格会**裁掉长的工作梳理**，全屏里高度跟着内容走，一行都不裁

用的是和首页预览区**同一个组件**，只是把高度放开、字号放大一点，样式完全一致。

### 🔒 红线一个字没动
- 压缩包文件名、内层 Excel 文件名、Excel 内容与样式：**完全没改**
- 解压密码规则、加密格式（AES-256）：**完全没改**
- `XlsxWriter` / `EncryptedZipWriter` / `ReportNaming` / `DateUtils` 四个文件与 v1.4.3 **逐字节相同**
- 新增回归测试：导出的 xlsx 与基线的 10 个 XML 部件**逐字节比对**
- 单元测试 187/187 通过
