# 更新记录

## v1.3.7（2026-10-22）· 当前版本

### 📨 邮件发送回到标准通道
复盘发现：**WebView 旧版（以及原生版最早几版）从来都是用一条标准通道发邮件的**，
从没做过任何特殊处理：

```
Intent(ACTION_SEND)
  type            = "application/zip"
  EXTRA_STREAM    = 附件 URI
  clipData        = 附件 URI
  EXTRA_SUBJECT   = 主题（与压缩包名完全一致）
  EXTRA_TITLE     = 主题
  EXTRA_TEXT      = 正文（留空）
  setPackage(目标邮箱 App)
```

而 v1.3.3 起为阿里邮箱加的**专用通道**（`setComponent` + `ACTION_SENDTO`）反而引入了两个问题：
点发送闪退、邮箱 App 根本拉不起来。现已**全部撤销**，各家邮箱 App 统一走上面这条标准通道，
附件一定带得上。只有阿里邮箱额外加一个 `CLEAR_TASK` 标记，绕开它写邮件页复用旧实例导致附件不处理的问题。

同时新增 `MailIntentSpec` 纯数据类 + 10 条单元测试，把「附件一定在 Intent 里、
主题非空、正文为空」这些变成**可自动验证的断言**，不再靠实机反馈才发现问题。

## v1.3.6（2026-10-22）

### 📝 首页表单草稿暂存
此前除姓名外所有输入都只在内存里，退出即丢。现在每次输入都会暂存到本机
（`SharedPreferences` + Base64 纯 Kotlin 编解码，不依赖 Android 的 `org.json` 空壳），
下次打开自动恢复。**生成压缩包成功后才清空草稿**，界面内容保留供当场核对。

## v1.3.5（2026-10-22）

### ✂️ 彻底移除「自动带入收件人」
邮件只带**主题 + 附件**，收件人由你在邮箱 App 里自己填。
原因很实际：附件与收件人分属 `ACTION_SEND` / `ACTION_SENDTO` 两套标准字段，
为每个邮箱 App 单独适配是个无底洞。去掉之后只剩一条通道，反而更稳。

### 🏷️ 首页文件名显示修复
文件名从三等分格子改为**独占一行**，25 字符的中文文件名不再被截断。

### ⚠️ 加入免责声明
「关于」页新增：本软件为个人自用效率工具，使用者需自行确保内容真实合法，
不得用于伪造工作记录、隐瞒实际工作内容或违反单位规定及法律法规，后果自负。

## v1.3.4（2026-10-22）

### 🐛 修复 v1.3.3 引入的闪退
`intent.selector` 搭配 `Intent.createChooser()` 会触发系统 ResolverActivity 的 NPE，
表现为点发送就闪退；同时 filter 未声明 scheme/mimeType 时，带 data URI 的 Intent 一律不匹配，
导致邮箱 App 拉不起来。两个问题一并修掉。

## v1.3.0（2026-10-22）

### 🎉 原生重写正式版
整个 App 从 WebView 套壳改写为 **Kotlin + Jetpack Compose 纯原生实现**，
不再加载任何网页资源（依赖树无 `androidx.webkit`，APK 内无 HTML/JS，源码无 WebView 引用）。

导出的 **Excel 与加密 ZIP 与旧版逐字节一致** —— 10/10 个 XML 部件实测比对完全相同，
关键细节包括：XML 声明后 CRLF、其余 LF、单元格换行保留字面 LF、空单元格为 `<v></v>`。

交叉验证另抓出并修复 3 个真 Bug：
1. `DateUtils.getThursday()` 把 `Date` 强转 `Calendar`
2. `DateUtils.getWeekRange()` 因 Calendar 周日=1、JS 周日=0 而整周偏移一天
3. Kotlin 字符串 `"$year年"` 被解析成标识符 `year年`

### 📋 其他

- 生成后自动拉起邮箱 App 发送（可记住选择）

- **iPhone Safari**：输入框字号提到 16px（低于 16px 时 Safari 聚焦会强制放大整页且缩不回）、
  `100dvh` 替代 `100vh`、刘海屏与底部安全区、触屏取消 hover 高亮、弹窗可滚动

### 🐛 修复部署平台注入脚本打断页面 JS
托管平台会在 `</body></html>` 处注入统计 `<script>`，而 SheetJS 源码里正好有同名字符串字面量，
注入点落进字符串内部导致整个 script 块语法崩溃、线上白屏（本地 `file://` 却完全正常）。
已把该字面量改成拼接写法，使源码中不再出现 `</body` 连续子串。
