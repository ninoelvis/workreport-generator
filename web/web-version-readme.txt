工作报告生成器 · 网页版 v1.3（离线可用）
=======================================

使用方法
--------
1. 把本目录下的 workreport-web.htm 拷贝到电脑或手机。
2. 用 Chrome / Edge / Safari 等现代浏览器打开该文件（双击即可）。
3. 填写姓名、本周工作时间、本周已完成工作梳理、下周工作计划。
4. 点「生成加密ZIP下载」，浏览器会直接下载加密后的 .zip 压缩包。
5. 弹窗里会显示解压密码（默认取本周周四日期，格式 yyyyMMdd）和文件名。

无需联网、无需安装，所有计算都在本机浏览器内完成，数据不会上传到任何服务器。

-----------------------------------
  OK  生成 Excel 周报并压缩为加密 ZIP、下载到本机
  OK  实时预览最终 Excel 效果（与导出的文件逐字一致）
  OK  工作记录管理与一键汇总
  OK  工作记录上下排序（▲▼）
  OK  脱敏按处放行：每一处独立开关、带上下文，同句重复出现可只放行其中一处
  OK  历史报告：列表 / 预览 / 载入继续编辑 / 再下载 / 再分享 / 取回下周计划
  OK  快捷模板：本周、下周两套，可复制给别人导入
  OK  配置备份与恢复（加密 ZIP）
  OK  「取回下周计划」：上一份报告的计划拆成一条条进工作记录
  OK  生成成功后自动清空工作记录与周报内容
  OK  分区清除 / 清除全部数据
  OK  浅色 / 深色主题切换
  OK  敏感词管理
  OK  生成后自动复制文件名到剪贴板（含非安全上下文兜底）
  OK  系统分享：iPhone 上直接分享到「邮件」/「文件」/微信
  OK  加密 ZIP 为 AES-256 + HMAC-SHA1（WinZip AE-1），

      导出的 xlsx 10 个 XML 部件与原生版完全相同

网页版做不到的（建议用安卓原生版）
----------------------------------
  ✗  定时周报提醒：网页版没有后台运行能力，关掉页面就收不到提醒
  ✗  自动拉起邮箱并带附件：浏览器不允许网页直接发附件邮件
  ✗  可靠的通知权限：网页版只能在部分桌面浏览器申请，iPhone 上基本不可用
  ✗  直接存到手机「下载」目录：网页版要自己选保存位置
  ✗  长期可靠的历史：网页版历史在浏览器 localStorage，清缓存就没了
