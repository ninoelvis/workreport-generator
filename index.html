⚠️ 安装提示

下载后如系统提示「未知来源」，请前往 设置 → 应用 → 特殊应用权限 → 安装未知应用，允许所用浏览器安装后重新点击下载链接即可。 安装包与历史版本使用同一签名证书，可直接覆盖安装升级，卸载重装则会清空本地草稿与敏感词库。

✨ 为什么推荐原生版
  • 无 WebView 依赖：整个应用为原生 Compose 界面，不加载任何网页资源，启动更快、内存占用更低。
  • 可覆盖安装：包名与签名证书与历史版本一致，升级不丢数据。
  • 完整功能闭环：历史报告归档与二次下载、敏感词库管理、深浅主题切换、压缩包直接作为附件拉起邮箱 App 发送。
  • 导出零妥协：导出的 Excel 与加密 ZIP 与早期版本逐字节一致（10 个 XML 部件实测比对通过），ZIP 采用 AES-256 + HMAC-SHA1（WinZip AE-1），WinZip / 7-Zip / NanaZip 等工具均可正常解压。

📱 关于 iOS / Safari 的使用说明

网页版的加密导出依赖浏览器 Web Crypto API（crypto.subtle）。依据 W3C Web 安全模型，该接口仅在安全上下文（Secure Context）中开放；经由 http:// 访问的页面不满足该条件，将导致加密导出不可用，因此建议始终通过 HTTPS 访问。

在 iOS 平台，系统未提供将本地 HTML 文件作为可执行网页打开的通用入口：文件预览器（Quick Look）不执行页面中的 JavaScript 脚本，Safari 亦不开放 file:// 协议下本地页面的完整能力。因此 iOS 设备请直接使用 HTTPS 在线版。

桌面端（Chrome / Edge / Safari）下载单文件版后，以 file:// 协议直接打开即可正常完成加密导出与下载，全过程无需联网。
